## Claude in Chrome が正式版に

8月26日、Chrome（クローム）の拡張機能「Claude in Chrome」がテスト段階を終え、**すべての有料プランで正式に使えるようになりました**（GA＝一般提供。「一部の人が試す」段階が終わって「誰でも正式に使える」状態のこと）。

**いちばん変わったのは「承認」です。**

| | これまで | これから |
|---|---|---|
| 操作の確認 | 1操作ごとに「これやっていい？」 | 安全と判断した操作は自動で承認して進む |
| 手が止まる場面 | クリックのたび | 重大な操作（送信・購入・削除）の前だけ |
| 戻し方 | — | 設定で「毎回確認」に戻せる |

自動承認は Claude Code の「オートモード」と同じ仕組みです。

**Claudeがブラウザでできること**（既存のログイン状態のまま）:

- 今開いているページを読む
- 検索窓・入力欄に文字を打ち込む
- リンクをクリックしてページを行き来する
- フォームを埋める

例: 「この一覧をスプレッドシートに写して」と頼むと、読み取り → 入力まで進めます。

**制限**: Chrome拡張のみ。他のブラウザ・スマホは対象外。ファイルの読み書きは今まで通りデスクトップアプリが必要です。

出典: <https://claude.com/blog/claude-in-chrome-generally-available> ✅

<a id="s-inject"></a>
## 勝手に動いて罠サイトを踏まないのか

Webページに「AIへの命令」を隠して仕込む攻撃を**プロンプトインジェクション**と呼びます。Claudeがそれを読んで、あなたが頼んでいないことをしてしまう危険です。Anthropic はこれに**3層の防御**で対策していると説明しています。

1. **訓練で鍛える** — 既知の攻撃を大量に学習させ、だまされにくくする（2025年11月から大きく改善）
2. **プローブが走査** — Webの内容をスキャンし、怪しい指示があれば Claude に警告。行動前にユーザーへ確認
3. **分類器が照合** — やろうとしている操作を「あなたが最初に頼んだこと」と照合。ズレていればブロック

**攻撃の成功率（プローブ＋分類器あり）**:

| モデル | 攻撃成功率 |
|---|---|
| Sonnet 5 | 0% |
| Opus 5 | 0% |
| Fable 5 | 0.3% |

数値は Anthropic が外部の攻撃専門家に依頼した強い攻撃に対するものです。以前は成功率0%まで到達したため、より強い攻撃を使う評価に切り替えたと説明されています。

### バランス — それでも気をつけること

- 「0%」でも油断しない。重大な操作の前では止まる設計なので、**止まったら押そうとしている内容を必ず読む**
- ファイル操作は今まで通りデスクトップアプリが必要
- 対象は Chrome拡張のみ

出典: <https://claude.com/blog/claude-in-chrome-generally-available> ✅

## 拡張版と Cowork 内蔵ブラウザの違い

同じ8月26日に、Claude Cowork（コワーク）にも**専用のブラウザが内蔵**されました。名前が似ていて混同しやすいので整理します。

| 観点 | Claude in Chrome（拡張機能） | Cowork の内蔵ブラウザ |
|---|---|---|
| 使う場所 | 今あなたが開いている Chrome | デスクトップアプリの中の別ブラウザ |
| ログイン | あなたのログイン済みアカウントで動く | あなたのタブ・ブックマーク・パスワードを一切見ない |
| 向いている用途 | 自分のアカウントでの作業代行 | 調べもの・切り分けたい作業 |
| 対象 | すべての有料プラン | Pro / Max / Team に順次、Enterprise は即日 |
| OS | — | macOS・Windows・Linux（Linuxはベータ） |

**どちらも既定で銀行・メール・SSO（ログイン共通化）のサイトは対象外**です。使いたい場合は自分で明示的に許可します。既に Claude in Chrome を使っている場合はそちらが既定のまま。設定 → Cowork → Preferred browser で切り替えられます。

出典: <https://claude.com/blog/cowork-built-in-browser> ✅

<a id="s-memory"></a>
## 記憶がチャットと Cowork で1つになる

8月25日、これまで別々だったチャットと Claude Cowork の記憶が**1つに統合**されました。Cowork に仕事を渡すと、チャットで話したプロジェクト・上司の好み・前四半期のクライアントを**そのまま前提に開始**します。

- **リアルタイム更新**: 会話が終わってから要約するのではなく、話している最中に記憶へ足していく。「覚えておいて」と言わなくても次の会話に反映される
- **編集できる**: 設定画面でトピック別に一覧表示。表示・編集・削除でき、**1か所直すと以降の全会話に反映**される

**自分のプランはどうなる**:

| プラン | 記憶の統合 | 備考 |
|---|---|---|
| Free / Pro / Max | 既定でオン | web・デスクトップ・モバイル |
| Team / Enterprise | 既定でオフ | 管理者が可否を決め、各自がオンにするまで無効 |

### バランス — 覚えてほしくないことはどうするか

- **既定で保存しない**: 健康・人種・民族・宗教的信条・政治的見解・性自認（設定でオンにでき、オン時は保存のたびに通知が出る）
- **設定に関係なく保存しない**: 社会保障番号・政府ID番号・犯罪歴・移民ステータス・利用規約に違反する内容
- iOS / Android は最新版アプリへの更新が必要

出典: <https://claude.com/blog/claudes-memory-works-everywhere-and-you-decide-whats-in-it> ／ <https://x.com/claudeai/status/2092299704864284888> ✅

<a id="s-cc"></a>
## Claude Code の地味に効く3つ

Claude Code（クロードコード）まわりで、小さいけれど効く改善が3つ続きました。

1. **表示が約4倍なめらかに**（8/25） — ストリーミング（回答が少しずつ流れる表示）のレンダラーを「変化し続けている部分だけを描き直す」方式に作り直した。低速なノートPCで長文返信の停止が**9倍少なく**、最悪のフリーズの長さが**4.5分の1**、120HzのMacBookでは最初から最後まで**120fps**を維持。※対象は Claude のウェブ版・デスクトップ版で、Claude Code 本体ではない点に注意
2. **フィードバックの下書きを自分で作る**（8/27） — 何かが失敗したとき・Claude が自分のミスに気づいたとき・「うまくいかなかった」と伝えたときに、Claude Code がレポートを自分で書く。送信前に確認・修正・承認できる
3. **ターミナルのセッションをアプリで再開**（8/29） — CLI（コマンド画面）で始めたセッションを、Claude Code デスクトップアプリで `/resume` から選ぶと、会話とコンテキストをそのまま保ったまま続けられる

出典: <https://x.com/ClaudeDevs/status/2092006814804214163> ／ <https://x.com/ClaudeDevs/status/2092695038270775647> ／ <https://x.com/ClaudeDevs/status/2093368017304371503> ✅

## 会社で Claude を使う人向けの2件

個人利用には直接効きませんが、背景として2件。

**MCPコネクタのエンタープライズ一元認証が一般提供**（8/25） — Claude に Gmail（ジーメール）や Slack（スラック）など外部ツールをつなぐ規格が **MCP**。Claude Team / Enterprise の管理者向けに、認証を社内のID基盤（IdP）経由で一元化できるようになりました。使う人は、コネクタごとに毎回ログイン許可を出さなくても、ツールとデータが自動でつながります。

## ChatGPT 側の今週

Claude に比べると小さめですが、自動化まわりで動きがありました。

- **スケジュールタスクが Webhook 対応**（8/25） — ChatGPT Work のタスクが、Gmailの新着・Slackチャンネルへの投稿・GitHubのPR更新に反応して動く。作成できるのは Plus と Pro（監視する Slack チャンネルに @ChatGPT を追加する必要あり）。タスクの共有も可能に。無料ユーザーはアクティブなタスク3つまで・1日1回まで・Webhookタスクは作成不可

- **Google アカウントを複数接続**（8/28） — Gmail・カレンダー・連絡先の各プラグインで複数アカウントを接続でき、個人用と仕事用を同じ会話に持ち込める。Plus / Pro / Business / Enterprise

## 「グラフエンジニアリング」論文

arXiv（アーカイブ）に「Graph Engineering in the Era of LLM Agents: From Individual Intelligence to System Intelligence」というサーベイ論文が出ました（著者35名・63ページ。v1が8月21日、v2が8月26日）。

- **言っていること**: プロンプトエンジニアリング → コンテキストエンジニアリング → ハーネスエンジニアリング → ループエンジニアリング、と続いた「1体のAIエージェントを強くする」路線には限界がある。複雑な仕事は「並行して進む作業」「互いに依存する作業」「独立した検証」「状態の保持」が混ざっており、1体に抱えさせると全部が一本道になる
- **提案**: 仕事の分解・エージェント間の役割分担と連携・実行中の状態の記録と復旧を、点と線のつながり（グラフ）として明示的に設計する。「モデルの知能 → 個の知能 → システムの知能」という見取り図

初心者は「1体より複数体の連携が次のテーマ」とだけ押さえれば十分です。

出典: <https://arxiv.org/abs/2608.21156> ✅

<a id="s-faq"></a>
## FAQ・注意点

**Q. 無料プランでも使える？**
Chrome操作は有料プランのみ。記憶の統合は Free / Pro / Max で既定オンです。

**Q. 覚えられた記憶は消せる？**
設定画面でトピック別に一覧でき、編集・削除できます。1か所直すと以降の全会話に反映されます。

**Q. スマホでもブラウザ操作できる？**
できません。Claude in Chrome は PC の Chrome 拡張のみです。

**Q. 会社アカウント（Team / Enterprise）だと？**
記憶の統合は管理者が可否を決め、各自がオンにするまで無効です。

**Q. 何から試すのが安全？**
ログイン不要の調べもの1件から。銀行・メール・SSO は既定で対象外です。
